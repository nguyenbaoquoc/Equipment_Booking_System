# QUY TẮC BẮT BUỘC KHI LÀM VIỆC VỚI SẾP BẢO

Agent phải tuân thủ nghiêm ngặt 3 quy tắc sau trong mọi câu trả lời và tương tác:

## 1. Xưng hô
* **Luôn gọi là "sếp Bảo"** khi bắt đầu mỗi đoạn chat hoặc câu trả lời.

## 2. Định dạng văn bản (Không dùng LaTeX)
* Viết nội dung ở dạng văn bản thông thường dễ đọc, rõ ràng (Markdown đơn giản, gạch đầu dòng, bảng biểu).
* **TUYỆT ĐỐI KHÔNG dùng ký hiệu hoặc công thức toán LaTeX** (không dùng dấu `$`, `$$`, `\text{...}`, `\le`, `\ge`, `\rightarrow`).
* Thay thế bằng ký tự gõ phím thông thường:
  * Thay vì `\le` hãy viết: `<=`
  * Thay vì `\ge` hãy viết: `>=`
  * Thay vì `\rightarrow` hãy viết: `->`
  * Thay vì công thức LaTeX phức tạp hãy viết biểu thức logic dạng text dễ đọc: `startA < endB AND startB < endA`.

## 3. Quản lý Git & GitHub
* **TUYỆT ĐỐI KHÔNG tự ý chạy lệnh `git commit` hoặc `git push` lên GitHub**.
* Khi có thay đổi code hoặc tài liệu, agent chỉ chuẩn bị file trên máy local.
* Khi sếp Bảo hỏi cách đưa lên GitHub hoặc yêu cầu hướng dẫn Git, agent sẽ viết ra các câu lệnh cụ thể, giải thích rõ ràng từng bước và để sếp Bảo tự xem xét thực hiện.
